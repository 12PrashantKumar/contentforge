Multi-agent content pipeline

An AI writer that won't publish what it can't prove.

Most AI writing tools will invent a statistic to sound convincing. ContentForge does the opposite — before it writes a claim, it checks the claim against its real source, and blocks the post if the evidence isn't there.

What makes it different

Two ideas, not a pile of features.

01 — the trust layer

It won't lie

Every factual claim is pulled apart, matched to evidence in the cited source, and judged. If the evidence isn't there — or the claim overstates it — the post is blocked. It fails closed: no proof, no publish.

02 — the interview layer

It asks, instead of inventing

For posts about my own work, it reads my commits and then interviews me — what did you build, what was the interesting part? It writes from my answer, so it never fabricates expertise I don't have.

The path a post takes

Six stages. Any one can stop it.

A post only ships if it clears every stage. Each stage can end the run cleanly — a system that looks like it works is more dangerous than one that visibly stops.
